# 🎓 Student Manager

A simple backend web application built with **Flask** and **SQLite** for managing student records. This project demonstrates CRUD operations, database integration, and basic web application development using Python.

## 🚀 Features

* ➕ Add new students
* 📋 View all student records
* ✏️ Edit student information
* 🗑️ Delete student records
* 💾 Store data using SQLite

## 🛠️ Technologies Used

* Python
* Flask
* SQLite3
* HTML
* CSS

## ▶️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Abdikarin-dev/student-manager.git
```

### 2. Install Flask

```bash
pip install flask
```

### 3. Run the application

```bash
python app.py
```

### 4. Open your browser

```
http://127.0.0.1:5000
```
